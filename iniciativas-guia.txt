- una iniciativa es una actividad que puede ser llevada a cabo por la organización
- cada una de ellas puede tener sub-iniciativas, y esas sub-iniciativas pueden tener las suyas también, y así sucesivamente
- esto está desligado del sistema de delegaciones. eso quiere decir que no necesariamente debe haber una delegación por iniciativa o viceversa. la estructura está hecha para máxima libertad de organización

ejemplos para llenar los campos:
- detalle
    - origen (dónde se originó la idea?)
        - comunidad (iniciativa comunitaria)
        - externo (fue propuesto por algo / alguien externo, especificar)
    - modelo económico (comercial, no comercial, híbrido / informal)
        - comercial (con fines de lucro)
        - no comercial (sin fines de lucro)
        - híbrido / informal
    - destinatarios (para quién es)
        - público (para todo el mundo)
        - miembros de SC
        - miembros de confianza de SC
        - contributores de la iniciativa
        - SC
        - clientes
        - invitados
        - individuos específicos
- estado
    - propuesto (lo pensamos y lo queremos hacer, pero todavía no sabemos si lo vamos a hacer)
    - lista de espera (lo vamos a hacer próximamente)
    - en desarrollo
    - pausado
    - abandonado (no se completó y no se está completando)
    - completado: operando
    - completado: no operando
    - completado: descontinuado (se completó y operó, pero ya no lo vamos a operar)
    - completado (para cosas que no se operan sino que se hacen una vez)
- etiquetas (pueden haber varias. en este campo, no usar otra cosa que no sea alguna de éstas)
    - software
    - producto físico (incluye hardware informático)
    - servicio
    - infraestructura
    - investigación
    - información
    - contenido
    - actividad
    - trabajo creativo
    - inversión
    - operación conjunta (dirigido por múltiples personas / entidades, SC participa)
    - otro: (especificar)
- sub-iniciativas
    - referenciar iniciativas que pertenezcan a ésta
    - si no hay, dejar vacío
